# ADR-0002：后台任务使用 PostgreSQL 自建队列

- 状态：Accepted
- 日期：2026-10-31
- 决策者：仓库维护者
- 相关：[ADR-0001](0001-rust-backend.md)、[平台需求](../product/platform/requirements.md)

## 背景

批量生成、图片渲染、配额月度重置、过期分享物清理都需要在请求之外执行。硬性要求：

- 教师提交后可以离开页面，任务必须继续执行。
- 任务不能因为进程重启或崩溃而丢失。
- 不引入额外中间件（Redis 等），减少备份面与运维面。
- 入队必须与业务写入保持事务一致，避免「反馈已创建但任务不存在」。

Rust 生态没有 pg-boss 的等价物，需要自行实现。

- 不做什么：不做多队列优先级体系、不做跨区调度、不做任务依赖图。

## 决策

在 PostgreSQL 中维护 `jobs` 表，使用 `FOR UPDATE SKIP LOCKED` 领取任务。设计要素逐项借鉴成熟实现，不自行发明：

| 借鉴来源 | 采纳的机制 |
| --- | --- |
| River | 事务内入队，业务回滚则任务不存在 |
| Oban | 状态机、`dedupe_key` 唯一任务、完成后定期清理 |
| pgmq | `locked_until` 可见性超时，进程崩溃后自动回收 |
| graphile-worker | `locked_by` 标记与 advisory lock 保证定时任务单实例 |

必须满足的规则：

1. 入队与业务写入在同一个事务内完成。
2. 领取必须是单条 `WITH picked AS (SELECT ... FOR UPDATE SKIP LOCKED) UPDATE ... RETURNING` 语句。
3. 租约 120 秒，回收循环每 30 秒扫描一次 `locked_until < now()`。
4. `(kind, dedupe_key)` 在 `pending` / `running` 状态下唯一。
5. 默认最多 5 次尝试，退避为指数加抖动，超限转入 `failed` 而不是无限重试。
6. 定时任务通过 `pg_try_advisory_lock` 保证单实例。
7. worker 使用平台连接池领取任务，执行时按任务的 `tenant_id` 开启租户事务写业务数据。
8. 完成记录保留 7 天后清理。

## 后果

### 正面

- 少一个需要备份、监控与升级的中间件。
- 任务与业务数据天然一致，可在同一个备份中恢复。
- 队列行为可读、可查、可直接用 SQL 排障。

### 负面 / 代价

- 需要自己实现重试、退避、死信与清理逻辑，约 200 行。
- 高吞吐场景下 Postgres 队列会成为瓶颈（本项目远未触及）。
- 轮询有延迟，默认 1–2 秒，不适合毫秒级任务。

### 风险与缓解

- 风险：实现有漏洞导致任务丢失或重复执行。
  缓解：三条强制测试（并发唯一性、崩溃回收、毒任务隔离）；处理器一律幂等。
- 风险：长任务超过租约被误回收，造成重复执行。
  缓解：租约 120 秒远大于最长任务耗时（AI 约 20 秒，批量渲染约 10 秒）；处理器幂等。
- 风险：队列表无限膨胀。
  缓解：完成记录 7 天清理；监控队列深度与最老 `pending` 年龄。

## 备选方案

| 方案 | 优点 | 缺点 | 未采用原因 |
| --- | --- | --- | --- |
| apalis | 现成重试与 backoff | 成熟度低一档，多一层不熟悉的抽象 | 出问题时排查成本高于自建 |
| River 的 Rust 客户端 | 成熟设计直接复用 | 主实现与文档在 Go 侧，Rust 客户端较新 | 需要的能力很小，自建更可审计 |
| pgmq 扩展 | SQS 语义完整 | 需要安装数据库扩展，增加部署约束 | 单机部署不引入扩展 |
| Redis + BullMQ | 生态成熟 | 多一个需要备份与监控的组件；无法与业务事务一致 | 违背最小依赖原则 |
| 前端并发编排 | 零后端实现 | 关页即中断，不满足需求 | 不满足「可离开页面」的硬要求 |

## 验证方式

- 命令或检查项：
  - 入队 200 个任务、并发 8 个 worker，断言每个 `id` 恰好被领取一次。
  - 领取后丢弃连接模拟崩溃，运行回收后断言任务回到 `pending` 且 `attempts` 增加。
  - 注入永远失败的任务，断言其最终进入 `failed` 且不阻塞其他任务。
- 观察指标：队列深度、最老 `pending` 任务年龄、死信数量。
- 复核时间：M2 完成后一次，上线后每月一次。
