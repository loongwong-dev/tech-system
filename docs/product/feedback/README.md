# 课后反馈模块

教师按课次批量录入反馈要点，平台生成可发送给家长的文本，教师审核后分享。

- **类型**：项目需求
- **覆盖范围**：本模块的需求、Prompt 约束与冷启动计划。
- **不覆盖范围**：租户、权益、管理端与合规见 [平台需求](../platform/requirements.md)；技术设计见 [模块设计](../../design/feedback/README.md)。

| [冷启动计划](launch.md) | 阶段与退出条件、陪跑内测 SOP、邀请码节奏、内容获客与定价实验 |
