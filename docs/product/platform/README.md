# 平台需求

跨模块的产品规则：租户、账号、权益、管理端、非功能、合规与里程碑。

- **类型**：项目需求
- **覆盖范围**：所有功能模块共用的平台规则与发布约束。
- **不覆盖范围**：具体模块的业务规则见 [课后反馈](../feedback/requirements.md) 等模块目录。

## 文档

| --- | --- |
| [需求说明](requirements.md) | 定位、角色、租户与权益、管理端、非功能、指标、合规、里程碑 |

## 边界

- 模块特有的流程、实体与交互写入对应模块目录，不写进本目录。
- 平台规则变化会影响所有模块，修改前先确认兼容性。
