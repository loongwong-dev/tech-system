# 平台设计

跨模块的系统契约：认证、数据模型、API 契约与前端壳。

- **类型**：项目设计
- **覆盖范围**：全系统共享的表结构、接口、认证与前端基础结构。
- **不覆盖范围**：模块专有规则见 [模块设计](../feedback/README.md)；工程规范见 [工程规范](../engineering/README.md)。

## 文档

| 文档 | 内容 |
| --- | --- |
| [认证与安全](authentication.md) | 会话、注册、密码、CSRF、限流、双因素、分享链接 |
| [数据库设计](database.md) | 表结构、索引、行级安全、删除策略、配额扣减、迁移规则 |
| [API 契约](api-contract.md) | 路由分组、端点、错误码、分页、幂等、契约生成 |
| [前端架构](frontend.md) | 共享边界、状态管理、离线草稿、流式渲染、微信兼容、性能预算 |

这些文档描述全系统共享契约，会包含当前模块的表、端点与页面。模块特有的规则、算法与交互写入对应模块目录，并在模块 `README.md` 中建立映射。
