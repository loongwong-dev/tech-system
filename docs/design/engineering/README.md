# 工程规范

跨模块的代码组织与测试规则，适用于所有业务模块。

- **类型**：项目设计
- **覆盖范围**：Rust 与 TypeScript 的组织方式、规模上限、可见性、错误处理与测试策略。
- **不覆盖范围**：模块的业务规则与数据结构见对应模块目录；本项目的技术选型见 [平台设计](../platform/README.md) 与 [ADR](../../adr/README.md)。
